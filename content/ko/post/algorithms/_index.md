# 알고리즘 완전 정복 가이드

각 알고리즘의 **핵심 개념**부터 **완전한 구현 코드**까지, 실전에서 바로 사용할 수 있는 완벽한 알고리즘 레퍼런스입니다.

## 카테고리별 알고리즘

### 기초 자료구조
- [스택(Stack)](./stack/) - LIFO 구조의 완벽한 이해
- [큐(Queue)](./queue/) - FIFO 구조와 다양한 응용
- [덱(Deque)](./deque/) - 양방향 삽입/삭제 자료구조
- [힙(Heap)](./heap/) - 우선순위 큐의 핵심 구현

### 정렬 알고리즘
- [버블 정렬](./bubble-sort/) - 기초적인 정렬의 이해
- [선택 정렬](./selection-sort/) - 최솟값 찾기 원리
- [삽입 정렬](./insertion-sort/) - 부분 정렬의 효율성
- [병합 정렬](./merge-sort/) - 분할 정복의 대표작
- [퀵 정렬](./quick-sort/) - 평균 최고 성능의 정렬
- [힙 정렬](./heap-sort/) - 힙을 이용한 안정적 정렬
### 탐색 알고리즘
- [선형 탐색](./linear-search/) - 기본적인 순차 검색
- [이진 탐색](./binary-search/) - 정렬된 배열의 빠른 검색
- [매개변수 탐색](./parametric-search/) - 최적화 문제의 핵심

### 그래프 알고리즘
- [BFS (너비 우선 탐색)](./bfs/) - 레벨별 탐색의 완벽 구현
- [DFS (깊이 우선 탐색)](./dfs/) - 재귀와 스택 활용법
- [다익스트라](./dijkstra/) - 최단 경로의 대표 알고리즘
- [플로이드-워셜](./floyd-warshall/) - 모든 쌍 최단 경로
- [크루스칼](./kruskal/) - 최소 신장 트리 구현
- [프림](./prim/) - 정점 중심 MST 알고리즘

### 동적 계획법
- [피보나치 DP](./fibonacci-dp/) - DP의 기초 완벽 이해
- [배낭 문제](./knapsack/) - 0-1 배낭과 무한 배낭
- [LIS (최장 증가 부분 수열)](./lis/) - O(n log n) 최적화
- [LCS (최장 공통 부분 수열)](./lcs/) - 2차원 DP의 대표
- [편집 거리](./edit-distance/) - 문자열 유사도 계산

### 문자열 알고리즘
- [KMP](./kmp/) - 효율적인 패턴 매칭
- [라빈-카프](./rabin-karp/) - 해싱 기반 문자열 검색
- [접미사 배열](./suffix-array/) - 문자열 전처리의 핵심
- [트라이(Trie)](./trie/) - 문자열 집합의 효율적 저장

### 수학 알고리즘
- [유클리드 호제법](./gcd/) - 최대공약수와 최소공배수
- [소수 판정](./primality-test/) - 에라토스테네스의 체
- [빠른 거듭제곱](./fast-exponentiation/) - 효율적인 거듭제곱
- [중국인의 나머지 정리](./chinese-remainder/) - 합동식 해법

## 난이도별 학습 경로

### 초급자 (Bronze~Silver)
1. 기본 자료구조 → 2. 기초 정렬 → 3. 선형/이진 탐색 → 4. BFS/DFS 기초

### 중급자 (Gold)
1. 고급 정렬 → 2. 기본 DP → 3. 그래프 심화 → 4. 문자열 기초

### 고급자 (Platinum)
1. 고급 DP → 2. 고급 그래프 → 3. 문자열 심화 → 4. 수학 알고리즘

## 사용법 가이드

각 알고리즘 페이지는 다음과 같은 구조로 되어 있습니다:

```markdown
개념 설명        # 알고리즘의 핵심 아이디어
시간복잡도       # Big-O 분석
완전한 구현 코드  # 바로 사용 가능한 코드
최적화 팁        # 성능 향상 방법
실전 예제       # 백준/프로그래머스 문제
변형 문제       # 응용 문제들
```

## 활용 팁

1. **개념 우선**: 코드를 보기 전에 개념을 완전히 이해하세요
2. **직접 구현**: 코드를 보고 따라치지 말고 스스로 구현해보세요
3. **시간복잡도**: 각 알고리즘의 시간/공간 복잡도를 정확히 외우세요
4. **실전 연습**: 제공된 예제 문제들을 반드시 풀어보세요
