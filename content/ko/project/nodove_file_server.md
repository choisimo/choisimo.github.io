## Go 기반 파일 서버

### 기술스택
- **언어**: Go
- **프레임워크**: Gin 프레임워크
- **아키텍처**: RESTful API 구조

### 특징
- RESTful API 구조의 파일 서버
- 포트 39495에서 실행
- 라우터 기반 아키텍처
- 고성능 파일 처리

### 주요 기능
- 파일 업로드/다운로드 서비스
- RESTful API 엔드포인트
- 효율적인 파일 관리
- 안전한 파일 전송

### 용도
파일 업로드/다운로드 서비스를 제공하는 백엔드 시스템으로, 웹 애플리케이션에서 파일 관리 기능을 담당합니다.
