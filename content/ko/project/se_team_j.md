## 소프트웨어 공학 팀 프로젝트

### 프로젝트 개요
SRS(Software Requirements Specification) 문서 관리를 위한 팀 프로젝트

### 특징
- 체계적인 요구사항 명세서 작성
- 버전 관리 시스템 활용
- 회의록 및 문서화 시스템
- 팀 기반 협업 도구

### 주요 내용
- **문서 관리**: SRS 문서 체계적 관리
- **요구사항 분석**: 시스템 요구사항 명세화
- **버전 관리**: Git 기반 문서 버전 관리
- **협업 도구**: 팀 커뮤니케이션 시스템

### 도메인 영역
자동차 제어 시스템 개발
- 자동차 잠금장치 시스템
- 엔진 상태 모니터링
- 차량 제어 인터페이스

### 기술 구성
- 문서화 도구 활용
- 협업 플랫폼 사용
- 프로젝트 관리 방법론 적용

이 프로젝트는 소프트웨어 공학의 체계적인 개발 프로세스를 학습하고 실습하는 학술적 프로젝트입니다.
