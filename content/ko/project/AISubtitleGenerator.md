## 개요
AI 자막 생성기는 인공지능을 활용하여 영상의 음성을 인식하고 자동으로 자막을 생성하는 프로젝트입니다. 다양한 언어를 지원하며 정확한 음성 인식과 자막 동기화 기능을 제공합니다.

## 기술 스택
- Python
- 음성 인식 AI 모델
- FFmpeg
- 자연어 처리

## 주요 기능
- 음성 자동 인식 및 텍스트 변환
- 다국어 지원
- 자막 포맷 커스터마이징
- 영상과 자막 동기화 조정
- 배치 처리 기능
