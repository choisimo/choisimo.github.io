## 개요
코드 머저는 여러 소스 파일을 효율적으로 병합할 수 있는 도구입니다. 이 프로젝트는 복잡한 코드베이스에서 코드를 통합하고 관리하는 데 도움이 됩니다.

## 기술 스택
- TypeScript
- Node.js
- Git 통합

## 주요 기능
- 다양한 프로그래밍 언어 지원
- 충돌 해결 도구
- 자동 코드 포맷팅
- 병합 히스토리 추적
