## 개요
AI 기반 마이크로블로깅 애플리케이션은 최신 Azure 서비스와 OpenAI GPT-4o를 활용한 풀스택 웹 애플리케이션입니다. 사용자들이 짧은 글을 게시하고 AI의 도움을 받아 콘텐츠를 개선할 수 있습니다.

## 기술 스택
- Azure Static Web Apps
- Azure Functions
- Remix SSR (Server-Side Rendering)
- Azure OpenAI GPT-4o
- React
- TypeScript

## 주요 기능
- AI 기반 글 작성 지원
- 콘텐츠 자동 요약 및 태그 생성
- 실시간 업데이트 및 알림
- 사용자 인증 및 권한 관리
- 반응형 디자인
