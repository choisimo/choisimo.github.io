## SFTP 파일 모니터링 시스템

### 기술스택
- **런타임**: Node.js
- **프로토콜**: SSH2 SFTP
- **인증**: JWT 기반 인증
- **알림**: 웹훅 시스템

### 특징
- 실시간 파일 변화 감지
- 웹훅 알림 시스템
- JWT 기반 보안 인증
- 자동 재시도 메커니즘

### 주요 기능
- **모니터링**: 원격 서버 파일 변화 실시간 추적
- **알림**: 웹훅을 통한 즉시 알림
- **보안**: JWT 토큰 기반 안전한 접근
- **안정성**: 연결 실패 시 자동 재시도

### 핵심 구성요소
- SFTP 연결 관리
- 파일 시스템 모니터링
- 웹훅 이벤트 처리
- 인증 및 보안 시스템

### 용도
원격 서버의 파일 변경사항을 실시간으로 추적하고 관련 팀에게 즉시 알림을 제공하는 모니터링 솔루션입니다.
