## 안전 신고 앱 (객체 탐지 기반)

### 기술스택
- **프레임워크**: Next.js
- **언어**: TypeScript
- **라이브러리**: React
- **UI**: Lucide 아이콘, 커스텀 UI 컴포넌트

### 핵심 기능

#### 📸 이미지 수집
- 카메라를 통한 실시간 촬영
- 갤러리에서 기존 이미지 선택
- 이미지 품질 최적화

#### 📍 위치 정보
- GPS 기반 자동 위치 수집
- 정확한 좌표 정보 추출
- 위치 기반 컨텍스트 제공

#### 🤖 AI 분석
- 객체 탐지 AI 모델 통합
- 실시간 이미지 분석
- 위험 요소 자동 식별

#### 🗺️ 지도 연동
- 신고 위치 지도 표시
- 주변 정보 제공
- 경로 및 접근성 정보

### UI/UX Features
- 반응형 모바일 디자인
- 직관적인 사용자 인터페이스
- Lucide 아이콘 활용
- 접근성 고려 설계

### 용도
AI 기반 객체 탐지 기술을 활용하여 안전 위험 요소를 자동으로 식별하고 신고할 수 있는 스마트 안전 관리 애플리케이션입니다.
