## 개요
이 프로젝트는 Nginx 서버에 인공지능 파일 분석 기능을 추가한 웹 기반 파일 브라우저입니다. 사용자가 업로드하거나 저장된 파일의 내용을 인공지능이 자동으로 분석하고 메타데이터를 추출합니다.

## 기술 스택
- TypeScript
- Nginx
- 인공지능 분석 API
- React 

## 주요 기능
- 직관적인 파일 탐색 및 관리 인터페이스
- 파일 미리보기 및 메타데이터 표시
- AI 기반 파일 내용 분석 및 요약
- 파일 검색 및 필터링
- 권한 관리 시스템
